# LLM 시험지 & 채점기

AI한테 일을 맡기기 전에 **시험을 보게 하는** 도구입니다.

```
python run_test.py --provider claude-cli --model claude-haiku-4-5

✅ [A-3] 정상주문
🟡 [A-4] 정상주문
      🟡 CAP-300-W 누락
      🟢 확인필요 1건 남발

========================================================
케이스 29건 · 무결점 28건 (97%)
🔴 치명 0   🟠 위험 0   🟡 누락 1   🟢 무해 0
========================================================
```

**맨 아랫줄만 보면 내놔도 되는지 알 수 있습니다.** 치명이 0이면 통과입니다.

이 저장소를 만들면서 겪은 이야기 → [AI한테 시험을 냈는데 출제자가 5번 틀렸다](https://velog.io/@ramses203/ai-exam-author-wrong-5-times)

---

## 왜 개수로 안 세고 등급으로 세나

"29문제 중 5개 틀렸다"로는 내놔도 되는지 판단할 수 없습니다. **어떤 5개인지**가 빠져 있으니까요.

오타 5개를 틀린 것과, "취소해 주세요"를 새 주문으로 잡은 것은 전혀 다른 사고입니다. 그래서 이 채점기는 **되돌릴 수 있는가**를 기준으로 4등급을 매깁니다.

| 등급 | 뜻 | 예제 도메인에서 |
|---|---|---|
| 🔴 치명 | 되돌릴 수 없다 | 엉뚱한 물건이 트럭에 실린다 |
| 🟠 위험 | 애매한 걸 확정했다 | 이번엔 맞았어도 다음엔 치명 |
| 🟡 누락 | 놓쳤다 | 사람이 발견할 수 있다 |
| 🟢 무해 | "확인해 주세요" 남발 | 느려질 뿐이다 |

원칙 한 줄 — **틀린 확정이, 확정 못 한 것보다 나쁘다.**

같은 28점도 이렇게 갈립니다.

```
치명 0 · 누락 1      →  내놓는다
치명 1 · 나머지 만점  →  못 내놓는다
```

## 예제로 들어 있는 것

거래처가 카톡으로 보낸 **주문 메시지를 상품 코드로 바꾸는** 파이프라인입니다.

```
입력   "안녕하세요 사장님, 택배박스 250 5박스랑 투명테이프 2박스 부탁드려요"
출력   택배박스 A형 250 — 5박스 / 박스테이프 — 「확인 필요」(48mm·60mm 후보 둘)
```

시험지 29문제는 이렇게 구성돼 있습니다.

```
A 정상 주문        4문제
B 주문이 아닌 것    6문제   ← 제일 많다. 최악의 사고가 여기서 난다
C 변경·취소        4문제
D 애매한 것        5문제
E 오타·줄임말      3문제
F 학습이 쌓인 뒤    7문제
```

**상품 목록(`data/item_master.csv`)에도 함정이 심어져 있습니다.**

- 투명테이프 2종 (48mm · 60mm) — 폭을 안 쓰면 특정 불가
- "250"으로 시작하는 상품 5종
- 한 박스 들이 수가 제각각 (50 / 40 / 25 / 10장)
- 낱개 상품도 섞임

함정이 없으면 시험은 다 통과하고, 실전 데이터를 넣는 순간 무너집니다.

## 쓰는 법

```bash
# 1. 케이스를 자기 도메인으로 바꾼다
vi data/cases.json          # 문제 + 정답지
vi data/item_master.csv     # 대조할 데이터 (함정 포함!)
vi prompts/intake.md        # AI한테 시킬 내용

# 2. 돌린다
python run_test.py --provider claude-cli --model claude-haiku-4-5 --out out_haiku
python run_test.py --provider gemini     --model gemini-3.5-flash  --out out_gemini

# 3. 채점 기준을 고쳤으면 — 모델 재호출 없이 다시 센다
python run_test.py --rescore --out out_haiku

# 4. 모델끼리 비교
python compare.py out_haiku out_gemini
```

### 케이스 파일 형태

```json
{
  "id": "F-4",
  "group": "학습후",
  "message": "테이프 60 2박스",
  "history": [["테이프", "TAPE-48-CL"]],
  "expect": {
    "orders": [["TAPE-60-CL", 2]],
    "non_order": [],
    "note": "🔴 명시 규격이 과거매칭을 이겨야 한다. 48을 내면 오출고"
  }
}
```

`note`에 **왜 이 문제를 넣었는지** 적어두세요. 안 적으면 석 달 뒤에 지워버립니다.

### 지원하는 호출 방식

| provider | 설명 |
|---|---|
| `claude-cli` | Claude Code 헤드리스. API 키 없이 구독으로 돈다 |
| `claude` | Anthropic API (`ANTHROPIC_API_KEY`) |
| `gemini` | Gemini API (`GEMINI_API_KEY` 또는 `.gemini_key` 파일) |

`claude-cli`는 `--safe-mode --tools ""`로 부릅니다. **이 두 옵션이 없으면 시스템 프롬프트가 3만 토큰 넘게 붙어서** 테스트가 오염되고 비싸집니다.

## 눈으로 보는 화면

```bash
python serve.py --provider claude-cli --model claude-haiku-4-5
# http://localhost:8777
```

메시지를 넣으면 판별 → 쪼개기 → 매칭 결과가 표로 나옵니다. 「확인 필요」 줄에서 후보를 클릭하면 그 매핑을 기억하고, 다음 분석부터 자동으로 확정합니다.

## 실전에서 물린 것들

이 코드에 들어 있는 방어 로직은 전부 실제로 당해서 넣은 것입니다.

**잘린 JSON 복구** — AI가 마지막 중괄호 직전에서 답을 끊어 보냅니다. 내용은 100점인데 형식 때문에 빵점 처리되던 걸, 열린 괄호 수를 세서 닫아줍니다(문자열 안쪽은 제외).

**판정 필드 우선 채점** — 어떤 모델은 「확인 필요」로 판정하면서 품목코드 칸에 유력 후보를 같이 채웁니다. 코드 칸을 먼저 읽으면 "확정해버렸네?"로 오독합니다. **AI가 잘한 것에 벌점을 주게 됩니다.**

**배치마다 즉시 저장** — 결과 파일 쓰기를 맨 끝에 두면 마지막 요청이 실패할 때 앞의 결과가 통째로 날아갑니다. 유료 API에서 한 번 당하고 고쳤습니다.

**429는 재시도하지 않음** — 무료 등급 쿼터가 "하루 N건"이면 재시도 한 번이 남은 할당량을 까먹습니다. 503(혼잡)만 재시도합니다.

## 파일

```
run_test.py          실행 + 채점
compare.py           모델별 결과 비교표
serve.py + web/      브라우저에서 확인하는 화면
data/cases.json      시험지 29문제 + 정답지
data/item_master.csv 함정이 심어진 상품 목록 50개
prompts/intake.md    AI한테 시키는 내용
samples/             실제 모델 응답 예시 5건
```

## 시작하는 순서

```
1. 등급표를 먼저 쓴다.  무엇이 되돌릴 수 없는지 적는다
2. 치명 항목마다 케이스를 하나씩 만든다
3. 데이터에 함정을 심는다.  비슷한 게 여럿 있게
4. 채점기를 돌린다.  치명이 0인지만 본다
5. 틀린 게 나오면 프롬프트가 아니라 정답부터 의심한다
```

**5번이 제일 중요합니다.** 이 저장소를 만들면서 AI는 1번 틀렸고, 제가 쓴 정답지는 3번, 채점기는 2번 틀렸습니다.
